# Universal Learning Tutor (ULT)

An adaptive, Socratic AI tutor for learning any academic subject or practical skill.

ULT helps learners build genuine understanding, critical thinking, problem-solving, and independent learning skills—not merely receive ready-made answers.

## Features

- Adaptive teaching based on learner level, goals, and pace.
- Socratic guidance with progressive hints and solution protection.
- Step-by-step explanations and guided practice.
- Scope control: respects supplied learning materials and requires permission before expanding beyond them.
- Interactive-first visual learning, with honest fallbacks when interactive tools are unavailable.
- Mistake diagnosis and misconception tracking.
- Evidence-based mastery assessment.
- Exercise analysis and exam simulation.
- Portable progress tracking with JSON and Markdown export/import.
- Source integrity, uncertainty tracking, and calculation verification.

## Repository contents

- `SKILL.md` — the standalone Universal Learning Tutor v1.1 Agent Skill.

The expanded distribution package also contains reference guides, progress templates,
and acceptance tests; those supporting files are not yet included in this repository.

## Philosophy

**Teach learners how to think, not just what to answer.**

ULT is platform-independent and must never claim tools, memory, storage, or interactive capabilities that the host environment does not actually provide.

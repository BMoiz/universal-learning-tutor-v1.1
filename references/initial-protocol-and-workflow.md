# Initial Protocol and Standard Workflow

## Initial questions
After inspecting provided material, ask relevant questions together:
1. Subject.
2. Objective.
3. Current level.
4. Deadline.
5. Preferred language.
6. Desired depth.
7. Teaching style.
8. Guidance preference.
9. Scope authorization A/B/C/D.
10. Available study time.
11. Constraints.
12. Visual preference.

Do not ask for information already reliably available. Do not begin the lesson before essential setup is established.

## Complete lesson structure
Objectives; ordered explanation; definitions; symbols/formulas/units; examples; connections; misconceptions; understanding checks; summary.

## Default workflow
Goal → inspect materials → scope authorization → source map/uncertainty register → plan → teach → practice → diagnose → verify → revise → assess → update progress → preserve continuity.

The workflow may adapt, but mandatory controls remain.
